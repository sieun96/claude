# 인수인계: 클라우드 세션 → 로컬(VS Code) 세션

작성 2026-09-27. 클라우드 세션에서 한 작업을 로컬 세션이 이어받기 위한 문서다.
로컬 세션은 lansinoh 폴더(시트 OAuth 인증), 소재관리대장, 박시은 노션 데이터에 접근할 수 있다. 클라우드 세션은 접근할 수 없다.

> 이 저장소(`sieun96/claude`)는 **공개**다. OAuth json, 계정 정보, 란시노 매출·광고 데이터는 절대 커밋하지 않는다.

## 3. 로컬 세션에서 할 일

### 3-1. 메타 분석 보고서 이어서 진행
- 용도: 보고 + 포트폴리오 반영.
- 결과 숫자는 아래 칸으로 연결: 데일리 10/29 “10월 결산”, 11/5 “절감률 확정”, 11/8 “운영 서사”, 면접 노트 2번(ROAS)·3번(원가) 슬라이드.

### 3-2. 계획 재검수 (노션 · 소재관리대장 대조)
사용자가 “실제 실무와 포트폴리오에 필요한 내용인지” 재검수를 요청했다. 확인할 것:
1. **실험 18건**이 실제로 있는가. 무엇의 실험인가(가격·옵션? 소재?). 그룹별 방문/주문 데이터가 있는가. 없으면 L08·L14·L16·L18을 소재 테스트 기준으로 바꾼다.
2. **소재 테스트 데이터**: 주 2~3회 세팅하는 소재 테스트의 노출·클릭·구매가 관리대장이나 메타 보고서에 있는가. 있으면 M1·M2 실습을 이 데이터로 바꾼다(가장 실무에 가깝다).
3. **소재관리대장 열**: 편당 원가 계산에 필요한 비용 열이 있는가. 10/1 과제 범위를 정한다.
4. **SKU 판매 예측 모델**이 실제로 있는가(랜덤포레스트→선형회귀). 없으면 M3(12월)를 줄이거나 뺀다.
5. **ROAS +32.1% 전후 비교**의 기간·조건이 맞는가. M4(1월) 범위를 정한다.
6. 면접 노트의 `[ ]` 칸 중 노션에서 바로 채울 수 있는 숫자.
7. MBA 종강일.

검수 결과로 `plan/plan.py`를 고치고 두 페이지를 재게시한다. 체크 기록은 날짜 키로 저장되므로 날짜를 옮기지 않으면 유지된다.

## 4. 사용자 질문에 대한 답(요약)

- **가설검정의 목적**: 관찰한 차이가 우연인지 실제인지 판단해서 소재 ON/OFF, 가격 채택 같은 결정에 근거를 붙이는 것. 진행: 사전(가설·주지표·최소 차이·표본·기간) → 실행(기간 전 판정 금지) → 사후(p값 + 신뢰구간) → 판정 기록.
- **시계열의 목적**: 전후 비교(ROAS +32.1%)에서 시즌·요일·추세를 걸러 조치 효과만 남기는 것. 판매 예측 검증에도 쓴다.

## 5. 로컬 세션에 붙여넣을 요청문

```

1) 메타 분석 보고서를 lansinoh/sheets OAuth로 시트를 읽어 이어서 완성
2) HANDOFF 3-2 항목을 노션·소재관리대장과 대조해서 plan/plan.py 수정 후 데일리·월간 아티팩트 재게시
3) 포트폴리오·면접 노트의 [ ] 칸 중 채울 수 있는 숫자 채우기
인증 파일과 회사 데이터는 커밋하지 마.
```
